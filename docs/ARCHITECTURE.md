# 架构方案

状态：2026-11-02 已实现。对应运行时位于 src/，当前使用无存储适配器。

## 前端基础

使用 TypeScript、React、Vite 和 Motion，输出静态文件供 GitHub Pages 使用。当前不需要服务端框架。

首页只有游戏列表，游戏页面独立。静态站点采用 hash 路由或等效的 Pages 兼容方案；构建资源和音效以部署 base URL 为基准。

## 模块边界

```text
app / 页面导航与站点外壳
i18n / 语言偏好、双语上下文与关卡展示文案
credits / 共用片尾与成对双语条目
ui / 通用按钮、卡片、浮层、主题、动效参数
games / 游戏注册表
games/gravity-snake/core / 纯规则与状态转换
games/gravity-snake/levels / 关卡数据与版本
games/gravity-snake/view / 棋盘与操作控件
audio / 事件到 WAV 的映射与播放器
services / 成绩和进度的数据访问接口及适配器
```

不为了可能出现的游戏过早建立通用物理引擎。共享的是外壳、基础 UI、音频与数据契约，规则由每个游戏自己持有。

## 游戏规则

规则层接受状态与动作，返回新状态和领域事件。它不访问 DOM、React、音频、时间、随机全局状态或网络。

例如：移动动作 → 规则计算 → 新局面 + 吃苹果/增长/下落/落地/死亡/通关事件 → 渲染与音效分别响应。

确定后的规则使用独立的 `rulesVersion`；关卡包含 `id` 和 `version`。最终的棋盘边界、碰撞与出口处理以游戏需求中的确认结果为准。

输入和视觉播放之间需要明确状态：稳定可输入、动作/下落播放、死亡、通关。重开或退出使旧动画与异步回调失效。

## 不保存游戏数据

- 当前局面、苹果数和结算结果仅在内存中存在。
- 刷新后重新开始，不保存成绩或关卡进度。
- 不用 localStorage 或 IndexedDB 保存分数/进度，不增加远端请求、队列或离线同步。
- 默认数据适配器必须明确返回 `disabled` / `unsupported`，不能假装成绩提交成功。
- 当前 UI 不显示未接通的排行榜入口或“已保存”提示。

仅语言偏好保存到 `stupid-games.language.v1`；读取和写入均容忍浏览器禁用存储，不涉及游戏数据。贴图位于 `public/Art/gravity-snake/`，由 `art.ts` 统一按 `BASE_URL` 引用。

## 为未来后端保留的接缝

在单一组合入口注入 `GameServices`，至少明确区分以下能力：

| 能力 | 当前行为 | 将来的可替换实现 |
| --- | --- | --- |
| `submitRun` | 不保存，返回 disabled | 向服务端提交一次局记录 |
| `getLeaderboard` | 返回 unsupported | 分页读取指定游戏、关卡及规则版本的榜单 |
| `loadProgress` | 返回 disabled | 读取已认证用户的进度 |
| `saveProgress` | 不保存，返回 disabled | 带版本信息提交进度 |

所有适配器使用相同的类型与异步结果契约。展示层通过 capabilities 判断是否存在相关功能，不能以“暂时返回空数组”掩盖未接后端。

将来只在组合入口切换 no-storage 与 HTTP adapter，避免在棋盘组件里分散 `if (backendEnabled)` 和 fetch 调用。当前已实现最小空适配器，不实现无法验证的 HTTP 假后端。

### 局记录契约

未来提交的数据至少考虑：

- `schemaVersion`：数据契约版本。
- `runId`：一次局记录的唯一标识，便于幂等提交。
- `gameId`、`levelId`、`levelVersion`、`rulesVersion`。
- `outcome`、`applesCollected`、最终确认的分数。
- 已确认规则下可重放的动作序列；如果将来有随机关卡，携带种子。

客户端分数不能作为可信成绩。正式排行榜应由后端验证动作、关卡和规则，再生成可排名的成绩。当前不实现验证服务，也不选择认证或数据库提供方。

### 错误与取消

接口区分 disabled、未认证、网络失败、版本不兼容和成功。未来支持 `AbortSignal`；离开页面可以取消在途请求，避免把旧结果写回新游戏。

## 音频

资源位于 `public/Audio/`，浏览器构建后位于相应 base 下的 `Audio/`。固定文件名与用途见同目录 README 和 manifest。

占位文件为 44 字节合法空 PCM WAV。尚未替换时禁止播放空文件，避免重复加载或解码异常。替换后检查 WAV 有有效音频帧，再由用户确认接入。

播放器处理浏览器交互解锁、静音、重复触发和解码失败；播放失败不阻挡规则或按钮。游戏只发事件，不自行拼接资源路径。

## 发布边界

当前不创建自动部署流程。未来用户要求发布时，再完成 Pages 子路径构建、资源加载与音效核验，并按授权推送、部署。

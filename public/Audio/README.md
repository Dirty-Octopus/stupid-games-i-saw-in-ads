# 音效交接

固定目录：`public/Audio/<game-id>/`。全站共用声音放在 `public/Audio/shared/`。

2026-11-02 用户已替换全部 13 个正式 WAV：PCM、44.1 kHz、24-bit、立体声，全部为非空音频。manifest 中所有 `ready` 已设为 `true`。默认开启声音，首次指针或键盘操作解锁 Web Audio 并预加载；右上角可静音。静音、重开、换关或返回会取消当前及排队音效。

文件完整解码通过，时长 0.120～3.970 秒，单文件峰值为 −17.0～−0.9 dBFS；保留用户原始音量和文件，不裁剪长尾音。表中的建议长度是制作阶段参考，实际文件可比建议更长。

替换时保留目录和文件名。可用 PCM WAV，单声道或立体声都可；如果需要循环、多个变体或更改事件，交接时再明确。表中的时长是制作参考，不是硬性限制。

## 全站共用

| 文件 | 用途 / 触发时机 | 建议长度 |
| --- | --- | --- |
| `shared/ui-confirm.wav` | 点击游戏入口或确认按钮 | 约 50-150 ms |
| `shared/ui-back.wav` | 从游戏返回列表、关闭面板 | 约 50-150 ms |
| `shared/ending.wav` | 通关后的白光和感谢文字入场 | 约 500-1500 ms |

开场不自动播放声音，以免浏览器音频限制导致体验不一致。指向卡片不重复播放声音。

## 重力贪吃蛇

| 文件 | 用途 / 触发时机 | 建议长度 |
| --- | --- | --- |
| `gravity-snake/move.wav` | 一次有效的逐格移动 | 约 40-100 ms |
| `gravity-snake/blocked.wav` | 无效移动撞墙或碰到身体，阻挡但不死亡 | 约 60-150 ms |
| `gravity-snake/eat.wav` | 吃一个苹果并增长一次 | 约 100-250 ms |
| `gravity-snake/fall.wav` | 一次连续下落开始，计划为一次性声音，不按下落格数重复 | 约 150-350 ms |
| `gravity-snake/land.wav` | 连续下落后重新接触地块 | 约 80-180 ms |
| `gravity-snake/die.wav` | 掉出地图、被咬至不足两格或无路可走时失败 | 约 300-700 ms |
| `gravity-snake/win.wav` | 达到已确认的通关条件 | 约 500-1200 ms |
| `gravity-snake/restart.wav` | 重开当前关卡 | 约 100-250 ms |
| `gravity-snake/expand.wav` | 落地后，尾部叠格沿找到的路径展开 | 约 100-350 ms |
| `gravity-snake/bite.wav` | 最后一关怪物每次咬掉尾部三格 | 约 150-350 ms |

同一个状态转换不要层叠播放多次。死亡时不再触发落地音效。最终事件顺序随游戏规则确认后核验。

## 替换与发布流程

1. 用户制作声音并直接替换这些 WAV 文件。
2. 告知哪些文件已经完成；开发者检查格式、时长、实际音量和触发时机。
3. 将对应 manifest 条目的 `ready` 改成 `true`，接入播放器并在浏览器中核验。
4. 用户确认体验及音效后，再按指令推送与部署。

`manifest.json` 是资源清单；当前 13 个正式音效已完成文件解码和浏览器解码验证，`ready` 全部为 `true`。以后新增声音仍应先验证，再启用。

## MP4 动作参考

每个 WAV 对应一个独立、无音轨的 MP4，统一 1080p / 60 fps / 6 秒。打开本地 `production/audio-reference/index.html` 即可逐个查看；MP4 位于该目录的 `mp4/shared/` 和 `mp4/gravity-snake/`，与 WAV 使用相同基础文件名。

画面始终标出音效起点（00:00:02:00）、建议结束时间码及时间轴。绿色区间是建议发声范围，橙色标记是建议结束；参考片制作时声音尚未完成，结束点为建议尾音；当前已接入的正式声音以 WAV 实际长度为准。导出声音时不要保留参考片前面的两秒空白。游戏动作从实际规则重放，页面切换以本地截图呈现；这些视频用于动作与声音对齐参考。

参考片、截图、静帧和旧贴图备份全部位于 Git 忽略目录，不参与网页构建。生成脚本和说明在 `scripts/audio-reference/`，可用 `npm run audio:stills` 和 `npm run audio:render` 重新生成。
